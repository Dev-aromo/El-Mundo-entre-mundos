# El Mundo Entre Mundos

**Biblia oficial y manual de reglas de un universo narrativo de fantasía oscura y terror psicológico.**

Este repositorio contiene la biblia de worldbuilding de *El Mundo Entre Mundos*: cosmogonía, cronología histórica, sistema de magia, criaturas, geopolítica y facciones de un planeta fracturado entre humanos, dragones y las cicatrices dimensionales conocidas como "Los Sitios".

## 📖 Contenido

- `El_Mundo_Entre_Mundos_Biblia_Unificada.pdf` — Documento de referencia completo con toda la biblia del universo.

## ✍️ Sobre este proyecto

Este es un universo de autor, creado y mantenido por **aromo**. El contenido de este repositorio (lore, personajes, mecánicas, nombres propios y estructura narrativa) es un trabajo original protegido por derechos de autor.

## 🖋️ ¿Puedo escribir historias en este universo?

**¡Sí!** Este universo está pensado como un lienzo abierto para la creatividad. Puedes:

- Escribir fanfiction, relatos cortos, cómics, ilustraciones u otro contenido derivado ambientado en este mundo.
- Compartir esas creaciones de forma gratuita (blogs, redes sociales, foros, Wattpad, AO3, etc.).
- Usar la biblia como referencia para tus propias campañas de rol, worldbuilding personal o ejercicios de escritura.

## 🚫 Lo que no está permitido

- **Vender** relatos, libros, cómics, guiones, merchandising o cualquier otro producto (físico o digital) que utilice este universo, sus términos propios (Los Sitios, Hábiles, Elegidos, Bebedores, la Biomáquina, Las Cercanías, etc.), sus facciones o su cronología.

- Presentar este material o sus derivados como propios, ni reclamar la autoría original del universo.

En otras palabras: la puerta está abierta para crear y compartir por amor al mundo, pero cerrada para quien quiera lucrar con él sin permiso.
